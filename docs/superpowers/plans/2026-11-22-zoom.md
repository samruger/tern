# Zoom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** number keys zoom a box full window; the same number restores. Hiding is removed.
**Architecture:** `Screen.zoom: str | None` (a box name). `layout()` returns one full rect for it. `toggle(i)` becomes zoom.
**Tech Stack:** Python stdlib curses; tests `python3 -m unittest tests.test_tern`.
**Spec:** docs/superpowers/specs/2026-11-22-zoom-design.md

## Global Constraints
- tern repo is public: never commit web.json, web-cert.pem, keys, .env.
- Screens 100×30 up must still draw; tests must stay green.

## Review Focus
- Zoom then resize to/from merged: no crash, zoom cleared if the box isn't on the new view.
- Zoom then p: restored and flipped; numbers on page 2 are its own.
- Web: digits zoom in one tab, prefs from the browser never carry zoom; old `hidden` prefs are dropped quietly.
- Zoomed variants/profiles: rows beyond the old fixed height draw without overrunning the box.
- Bottom row with a flash while zoomed: the flash wins, as with the page hint.
